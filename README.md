# MiniHYSYS

MiniHYSYS is a lightweight steady-state process simulator inspired by Aspen HYSYS, focused on core process-simulation functionality without unnecessary enterprise complexity.

## MVP goals

- Steady-state simulation
- Basic material streams
- Core unit operations
- Thermodynamic property package abstraction
- Simple recycle convergence
- Lightweight flowsheet UI

## Repository structure

- `backend/` — FastAPI simulation backend
- `frontend/` — React/TypeScript frontend
- `examples/` — example cases

## Planned stack
